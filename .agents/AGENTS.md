# Workspace Guidelines - SuvarnaLoan ERP

## Credential & Super Admin Directives
- **NEVER change or reset passwords** for Super Admin created shop owner accounts unless explicitly instructed by the user.
- Whatever password the Super Admin sets during tenant creation/provisioning must be preserved exactly without alteration.
- Accounts provisioned by Super Admin are auto-confirmed (`email_confirm: true`) and immediately active for login without requiring any email verification.

## Git & Repository Directives
- **NEVER push code to GitHub or any remote repository** (`git push`, etc.) without explicit permission from the user.
